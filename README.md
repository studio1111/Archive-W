# Archive-W

آرشیو بصری کامپوننت‌های UI با تم Dark / Glass / RGB Neon و رابط RTL.

## وضعیت
این مخزن عمداً به‌صورت یک سایت استاتیک ساخته شده و بدون build step اجرا می‌شود.

## داده‌های 21st
21st یک کاتالوگ بزرگ از کامپوننت‌های React، template، shadcn theme و موارد دیگر است و هر قطعه صفحهٔ اختصاصی، preview و مسیر دریافت/نصب دارد. این پروژه کارت‌های Archive-W را به صفحات اصلی قطعات لینک می‌کند.

به‌دلیل حقوق نشر و شرایط استفاده، متن کامل کد و پرامپت‌های شخص ثالث در این مخزن دوباره منتشر نشده‌اند. به‌جای آن، هر کارت به منبع اصلی 21st لینک می‌شود و دستور نصب/اطلاعات لازم در UI قرار گرفته است.

## اجرا
فایل `index.html` را باز کنید یا با هر static host مانند GitHub Pages منتشر کنید.
